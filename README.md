# Shop Manager

A simple product catalog web application built with HTML, Tailwind CSS, and JavaScript.

## Features

- Display products from an API
- Search products by name
- Filter products by category
- Filter products by minimum and maximum price
- Filter products by stock availability
- Responsive product cards

## Technologies

- HTML5
- Tailwind CSS
- JavaScript (DOM, Fetch API, Async/Await)

## API

This project uses the [Shop Manager API](https://github.com/Said-Aabilla/shop-manager-api).

## How to Run

1. Clone the API repository.
2. Open a terminal inside the API folder.
3. Install dependencies and start the server:

   ```bash
   npm install
   npm start
   ```

4. The API runs at `http://localhost:3000`.
5. Open the Shop Manager `index.html` file in your browser.
